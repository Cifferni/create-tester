# test-cases/ — 测试人员的既有用例(输入源,零重写)

这里放**你已经有的测试用例**,支持:

- `Markdown`(.md)— 需求文档/用例文档,表格自动转成规整文本
- `Excel`(.xlsx / .xls)— 大批量用例管理,每个 sheet 自动转成表格文本
- `XMind`(.xmind)— 梳理测试点/场景,思维导图分支自动转成步骤列表
- `.csv` — 禅道 / TestLink / Jira 导出的用例
- `.txt` — 自然语言描述的操作步骤

**不需要改写成任何特定格式。** AI harness 通过 MCP 的 `convert_case` 读取它,自动理解并生成可执行的测试脚本(`tests/*.spec.ts`)。

Excel 示例(一个 sheet 一行用例,AI 会自动识别"步骤/预期"列):

| 编号 | 模块 | 标题 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| TC01 | 登录 | 正确账号登录 | 1.打开登录页 2.输入test01 3.输密码 4.点登录 | 进入首页,显示"欢迎您" |

XMind 示例(分支标题即步骤/预期,备注会一起读入):

```
登录
├── 正常登录
│   └── 用户名 test01 + 密码 123456 → 进入首页
└── 错误密码
    └── 密码错误 → 提示"用户名或密码错误"
```

TXT 示例(一个 `登录.txt`):

```
1. 打开登录页
2. 输入用户名 test01
3. 输入密码 123456
4. 点击登录
5. 预期:进入首页,显示"欢迎您"
6. 断言接口 /api/login 返回 code=0
```
